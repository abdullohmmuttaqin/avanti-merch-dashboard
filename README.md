# AVANTI MERCH Dashboard

A full-stack merchandise e-commerce website with customer storefront and admin sales dashboard built using PHP Native, MySQL, HTML, CSS, and JavaScript.

---

## Project Goals

This project is developed as a complete web-based merchandise selling platform for AVANTI MERCH, featuring both customer shopping pages and an admin management dashboard.

---

## Main Features

- Product Listing
- Product Detail Page
- Shopping Cart
- Checkout System
- Admin Login
- Admin Sales Dashboard
- Product CRUD Management
- Order Report

---

## Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP Native
- MySQL
- XAMPP
